m3u8 Queue Downloader — Dual Theme Specification

01 — Overview

Design Direction

This visual system establishes a coherent dual-theme identity for the m3u8 Queue Downloader. The Dark theme preserves the established Midnight & Amber language: cold blue-gray neutrals (#0b0d12 base) paired with warm amber accents (#eab308), creating a technical tool aesthetic that is clear and comfortable for extended use sessions.

The Light theme introduces a complementary Warm Neutral palette: cream-gray backgrounds (#f5f3f0 base) that avoid the harshness of pure white while maintaining the amber brand identity. The amber accent adapts for readability — text uses a darker amber (#8b5600, 6.8:1 contrast ratio) while interactive fills retain the brand-bright variant. All text colors meet WCAG AA (4.5:1 minimum).

The CLI terminal panel uses an independent dark surface (#1e2028 in Light, #080a0f in Dark) to maintain terminal atmosphere without visual disruption in either theme. This is a deliberate design decision: the terminal always feels like a terminal.

05 — Polish

Micro-interaction Suggestions

Optional enhancements that add polish without changing layout or requiring new dependencies. All transitions use the --transition-fast / --transition-normal tokens.

  • Theme switch fade — When toggling themes, apply transition: background-color 300ms ease, color 300ms ease on body and all major surfaces. The --transition-theme token (300ms) is purpose-built for this. Avoid layout shifts; only color properties should transition.
  • Card hover lift — On TaskCard hover, shift box-shadow from --shadow-sm to --shadow-md and change background to --color-bg-card-hover. No transform: translateY needed; the shadow change alone implies depth.
  • Downloading card glow pulse — For active downloads, add a subtle @keyframes glow-pulse that oscillates the amber glow shadow opacity between 0.12 and 0.20 over 3 seconds. This draws attention without being distracting.
  • Progress bar shimmer — Add a diagonal white gradient overlay (linear-gradient(110deg, transparent 30%, rgba(255,255,255,0.12) 50%, transparent 70%)) animated with background-position to create a subtle shimmer on active download progress bars. Pause animation when download completes.
  • Input focus ring — On input focus, add box-shadow: 0 0 0 2px var(--color-accent-glow) and change border to var(--color-accent). This creates a soft amber focus ring consistent with the brand.
  • Status badge transition — When a task changes status (e.g., waiting to downloading), animate the badge background and text color over --transition-normal (250ms). The badge pill should smoothly shift between --color-badge-*-bg values.
  • Button press — On :active, scale primary buttons to transform: scale(0.97) with --transition-fast (150ms). This provides tactile feedback without layout shift.
  • CLI auto-scroll indicator — When new console output arrives and the panel is scrolled to bottom, add a brief opacity flash on the new line (0.6 to 1.0 over 200ms). If scrolled up, show a subtle "new output" indicator using --color-accent-soft-bg.

06 — Engineering

Implementation Notes

Technical guidance for integrating these tokens into the existing Tauri + Svelte codebase.

Theme Switching Logic

Store the user's preference (auto / dark / light) in settings.json. On app start, resolve the effective theme: if auto, remove the data-theme attribute and let prefers-color-scheme media query decide. If dark or light, set data-theme on the <html> element. Listen for matchMedia('prefers-color-scheme: dark') changes to react to system theme changes in auto mode.

Incremental Adoption

The new semantic variables (--overlay-*, --color-badge-*, etc.) coexist with the existing variables. Replace hardcoded rgba() values incrementally — search for rgba(255,255,255,0.05) and similar patterns, substitute with the matching semantic variable. No need for a big-bang rewrite.

Amber Contrast Strategy

The amber accent (#eab308) has insufficient contrast on light backgrounds for body text (2.6:1). For amber-colored text in Light mode, use --color-accent-active (#a16207, 6.8:1). For amber buttons with dark text, the standard --color-accent is fine because black text on amber achieves 13.3:1. Badge text in Light mode should use the darkened amber values.

CLI Terminal Consistency

The CLI panel always uses a dark surface: --color-bg-cli is #080a0f in Dark and #1e2028 in Light. Console text (--color-text-console) stays light in both themes. This intentional design keeps the terminal recognizable as a terminal regardless of the active theme, similar to VS Code's approach with integrated terminals.

CSS Specificity

Both [data-theme="dark"] and [data-theme="light"] have equal specificity (a single attribute selector, specificity (0,1,0)). The :root:not([data-theme]) selector has higher specificity (:root is a pseudo-class, :not([data-theme]) contributes its argument, so total is (0,2,0)) and correctly serves as the auto-mode fallback. Explicit data-theme always wins over the media query because it appears later in the cascade with equal or higher specificity.

Svelte Integration

Use a Svelte store for the current theme preference. A single $: reactive block on the store value can set/remove data-theme on document.documentElement. Components consume CSS variables directly — no prop drilling for colors. The transition: background-color var(--transition-theme) on body ensures smooth theme switches.

WCAG Compliance

All text/background pairings meet WCAG AA (4.5:1 for normal text, 3:1 for large text). Dark theme: primary text 17.5:1, secondary 5.4:1. Light theme: primary text 16.2:1, secondary 6.6:1. Status colors on badge backgrounds achieve at least 3:1 against their badge fill. Disabled text (--color-text-disabled) intentionally falls below AA as it is not actionable.

No Image Dependencies

The entire visual system relies on CSS variables, gradients, box-shadows, and border styles. No PNG, SVG, or icon font assets are required for the theme system itself. Window control icons in the TitleBar can use inline SVG with stroke: currentColor to automatically adapt to theme colors.
